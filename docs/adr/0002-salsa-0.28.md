# 0002 — Salsa spine on salsa 0.28

**Context.** salsa 0.16 pulled `parking_lot` 0.11 and with it `instant`, unmaintained
(RUSTSEC-2024-0384) — found the first time the compiler's advisory gate ran (ADR-0004).
`deny.toml`'s policy is that advisories are fixed at the root, not ignored.

**Decision.** Rewrite `beck-db` on salsa 0.28's entity API: a `Source` input per module, tracked
functions for parse/expand/imports/interface/checked, the name→`Source` lookup on the `Compiler`
trait (add-only, un-tracked; an imported module never `set` is a panic, as before).

**Consequences.** The advisory is gone and `ignore = []` holds. The firewall is unchanged and
its tests prove it: a body edit re-checks one module, a signature change reaches importers —
backdating on interface equality survives the API translation.
