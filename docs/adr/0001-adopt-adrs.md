# 0001 — Adopt architecture decision records

**Context.** Rationale was accumulating in code comments and doc prose as narrative ("this was
broken", "we decided…"), which ages badly: the next reader needs the current rule, not the
story of how it was reached.

**Decision.** Engineering decisions get a record here. Docs and comments state current truth and
link to a record when the why needs history. `AGENTS.md` carries the comment rule.

**Consequences.** Comments get shorter. History survives, in one place, out of the way.
