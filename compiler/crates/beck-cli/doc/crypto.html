TokenError

union TokenError

The failure of a token that does not check out.

One variant with a reason rather than several: a caller distinguishing "the mac is wrong" from "the payload is not base64" would be distinguishing two ways of being handed a forgery, and both answers are the same answer.

digest_all

digest_all(parts: list[Str]) -> Str

defon anyno effects

The digest of several values, which is not the digest of their concatenation.

`["ab", "c"]` and `["a", "bc"]` concatenate to the same string and must not digest to the same one, or a program digesting a record's fields could be handed a different record with the same fingerprint. Each part carries its own length, which is the cheapest thing that makes the encoding unambiguous.

fingerprint

fingerprint(text: Str, width: Int) -> Str

defon anyno effects

A short, stable name for a value — the first `width` hex digits of its digest.

Shortening is the caller's decision and not this function's, because how much collision resistance a name needs is a property of what it names. A width past the digest's length is the whole digest rather than an error: asking for more than there is is not a mistake a program can recover from differently.

payload_if

payload_if(token: Str, mac: Str) -> Str

defon anyraises(TokenError)

The payload of a token whose code is `mac`, or a raised `BadToken`.

The comparison is `digest_eq` rather than `==`, because `==` returns at the first byte that differs and tells a caller who is guessing how much of the guess was right.
