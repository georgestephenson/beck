fixed

fixed(x: Float, places: Int) -> Str

defon anyno effects

`x` to exactly `places` decimal places, rounded half away from zero.

**The rounding rule is half away from zero and `printf`'s is half to even**, and the two differ only when the scaled value lands exactly on a half. A caller whose values are quotients or roots never meets one; a caller that computes in tenths meets one immediately, and wants [`decimal`](decimal.beck)'s `render_at`, which takes the rule as an argument and works in exact arithmetic rather than in binary floating point.

lines_of

lines_of(parts: list[Str]) -> Str

defon anyno effects

`parts` as lines, with a trailing newline.

The trailing newline is the point. A file written by a program that ends each line the way it ends every other differs from one that drops the last by a single byte, and by nothing a reader would see — so it is the sort of difference a comparison finds and an eye does not.

pad_zeros

pad_zeros(digits: Str, width: Int) -> Str

defon anyno effects

`digits` widened to `width` with leading zeros. Narrower than its input is its input.

The fractional part of a fixed-point number is the one place a leading zero carries information: `0.045` and `0.45` differ by the zero and by nothing else, so dropping it is a wrong answer rather than an ugly one.

ten_to_the

ten_to_the(n: Int) -> Int

defon anyno effects

Ten to the `n`, for `n` at or below the point where an `Int` stops holding it.

Nothing guards a larger exponent, because a caller that asked for one would be wrong about `Int` rather than about this function.
