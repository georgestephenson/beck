The value at `name` in a JSON object, or `JsonNull` — for a document, not a path.

A `Result` at the boundary and a total function inside it: the failure is *parsing*, and once the document is data there is nothing left to fail at. `unwrap_or(map_get(...), JsonNull)` is how a missing key becomes a value rather than a second error type.
